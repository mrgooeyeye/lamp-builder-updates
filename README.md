# Lamp Builder

Design industrial pipe lamps in an editable 3D workspace for macOS.

**[Download the latest version](https://github.com/mrgooeyeye/lamp-builder-updates/releases/latest)**

Requires an Apple silicon Mac (M1 or newer) running macOS 15 or later.

## Build and explore

- Assemble pipe fittings, flanges, bulbs, sockets, switches, and cable entries with compatible connection points.
- Rotate fittings, change mounting points, and fine-tune accessory placement.
- Work on multiple projects in tabs; save lamp designs into library collections.
- Brainstorm table, floor, and wall lamps with Lamp Engine, then customize the results.
- Review bills of materials, receipt scans, and actual purchase prices.
- View room context and estimated balance while designing.

Dimensions inferred from photographs, design suggestions, and balance estimates need verification against actual parts. The app does not certify structural or electrical safety.

## Install and update

Open the DMG, drag **Lamp Builder** into **Applications**, eject the DMG, and launch the installed app. Releases are Developer ID signed and notarized by Apple.

Lamp Builder 1.1.0 and later can check for updates automatically. You can also choose **Lamp Builder → Check for Updates…**. Installation asks before restarting; save your work first. Existing 1.0.0 installations need one manual upgrade to obtain the updater.

Projects and receipts are stored locally, separately from the application. This repository contains public downloads and update information, not your designs, receipts, or the application's source code.
