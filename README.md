# Lamp Builder

Design industrial pipe lamps in an editable 3D workspace for macOS.

The first public download is being prepared and is awaiting Apple notarization. No installer is available here yet.

When ready, installers will appear on the [Releases page](https://github.com/mrgooeyeye/lamp-builder-updates/releases).

Requires an Apple silicon Mac running macOS 15 or later. This repository contains public downloads and update information only.
